# GenAI Trust Lab

GenAI Trust Lab is a student website with a Python API behind it. The website has four tools: a Generator that makes small images, a Detector that scores whether an image looks real or AI-made, a Compare tool that shows how two images differ, and an Auditor that checks how close a generated image is to the training images. Nothing in this repository is a result yet: every number you see in the plans is a placeholder until it is measured.
